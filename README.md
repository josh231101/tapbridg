# TapBridg Landing Page

Static responsive landing page built with plain HTML, CSS and minimal JavaScript.

## Files
- `index.html` — page structure/content
- `styles.css` — full responsive styling and product/UI mockups
- `script.js` — mobile navigation, scroll reveal and experience switcher
- `assets/tapbridg-logo.svg` — vector logo asset

## Run locally
Open `index.html` directly in a browser, or serve the folder with any static server.

Example:
```bash
python3 -m http.server 8080
```
Then open `http://localhost:8080`.

## Notes
- No external libraries or web fonts are required.
- The page uses system fonts to preserve the clean Apple-like aesthetic and load instantly.
- Product/device visuals are CSS-rendered, so there are no external image dependencies.
